# 📱 How to Download Your EntryRank APK

**Quick Guide**: Get your Android APK in 3 simple steps!

---

## 🎯 Method 1: Download from GitHub Actions (Recommended)

### Step 1: Go to Actions Page
**Click this link**: https://github.com/maxin3820-jpg/entryrankapk/actions

### Step 2: Find the Latest Successful Build
Look for:
- **Green checkmark ✅** (successful build)
- **Latest workflow run** (top of the list)
- Click on the workflow name to open details

### Step 3: Download the Artifact
1. Scroll to the **bottom** of the workflow page
2. Find the **"Artifacts"** section
3. Click on **"entryrank-debug-apk"**
4. A ZIP file will download
5. **Extract the ZIP** file
6. Inside you'll find: **`app-dev-debug.apk`**

### Step 4: Install on Android
1. Transfer `app-dev-debug.apk` to your Android phone
2. Open the file on your phone
3. Tap **"Install"**
4. Done! 🎉

---

## 🎯 Method 2: Download from Releases (Easier)

### Step 1: Go to Releases Page
**Click this link**: https://github.com/maxin3820-jpg/entryrankapk/releases

### Step 2: Find the Latest Release
Look for:
- **Latest** tag at the top
- Release titled: "Release v1.0.X"

### Step 3: Download APK Directly
1. Under **"Assets"** section
2. Click on **`app-dev-debug.apk`**
3. APK downloads directly (no ZIP extraction needed!)

### Step 4: Install on Android
1. Transfer to your Android phone
2. Open the APK file
3. Tap **"Install"**
4. Done! 🎉

## 📱 Installing APK on Android

### For Android Phone/Tablet:

#### Option A: Direct Download on Phone
```
1. Open browser on your Android device
2. Go to: https://github.com/maxin3820-jpg/entryrankapk/releases
3. Tap on "app-dev-debug.apk"
4. Download completes
5. Tap "Open" in notification
6. Or open Downloads folder and tap the APK
```

#### Option B: Transfer from Computer
```
On Computer:
1. Download APK from GitHub (either method)
2. Connect phone via USB cable
3. Copy APK to phone's Download folder

On Phone:
4. Open file manager
5. Go to Downloads folder
6. Tap on app-dev-debug.apk
7. Follow installation prompts
```

#### Option C: Use Cloud Storage
```
1. Upload APK to Google Drive/Dropbox
2. Open Drive/Dropbox on phone
3. Download the APK
4. Tap to install
```

### Enabling "Unknown Sources"

If you see a warning about installing from unknown sources:

#### Android 8.0+ (Oreo and newer):
```
1. Tap "Settings" when prompted
2. Enable "Allow from this source"
3. Go back and tap "Install"
```

#### Android 7.x and older:
```
1. Go to Settings → Security
2. Enable "Unknown sources"
3. Confirm the warning
4. Return to installation
```

## ⚠️ Common Issues & Solutions

### Issue: "Can't find the green checkmark"
**Solution**: 
- Build might still be running (wait 5-8 minutes)
- Or build failed (look for red X and check TROUBLESHOOTING.md)
- Refresh the Actions page

### Issue: "No Artifacts section"
**Solution**: 
- Artifacts only appear after build completes successfully
- Check if the build has a green checkmark
- If build failed, fix errors and push again

### Issue: "No Releases found"
**Solution**: 
- Releases are only created on push to main branch
- Check Actions instead for artifacts
- Or wait for next push to main

### Issue: "APK won't install"
**Solution**: 
- Enable "Unknown sources" (see above)
- Make sure APK downloaded completely
- Check phone storage (need ~100 MB free)
- Try redownloading the APK

### Issue: "App crashes on launch"
**Solution**: 
- Check minimum Android version (need 8.0+)
- Try clearing app data and cache
- Uninstall and reinstall
- Report on GitHub issues with crash logs
